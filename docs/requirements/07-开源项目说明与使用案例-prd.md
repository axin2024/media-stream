# 分布式直播与点播平台｜开源项目说明与首个案例

**media-stream** 是面向自托管的 Go 项目。Go 管理会话和作业，FFmpeg 负责编解码，MySQL 管目录与录制索引。首版以 HLS 为公开播放链路。 本页作为后续公开使用手册的需求稿，实际发行时补入测试版本、安装入口与已验证的依赖组合。

## 准备

两个本地推流器、FFmpeg、HLS 播放器与自制三分钟样片。

同一段自制 120 秒素材用两路推送，在第 45 秒断开主路；两档码率输出，结束后导出回放。

## 第一次使用

1. 导入有使用授权且带时码的同一段样片，配置两个输入与两档画质。
2. 在一个播放器记录起播时间，直播到 45 秒停掉主输入，保留输入代际和播放器事件。
3. 核对备路接管、清单断点、恢复播放时延及观众实际卡顿时长。
4. 结束推流后打开点播，在切换点前后定位并下载剪辑，核对切点、字幕和源片序号。

## 对照综合样例

记录检测、切换与首个可播片段时间，切换处显式标记不连续；回放不重复计片，可定位断点并导出指定区间。 对照结果时保留源记录号、版本和操作时间，追踪从输入到最终交付的关联。

## 制造一次可恢复的异常

结束事件重复不会产生第二份公开回放。回到对象详情核对 recording 和审计记录，再按指定版本恢复或重试。确认相同操作不会生成两份有效结果。

## 自托管与反馈

观众鉴权与推流鉴权分开。技术指标区分源中断、转码积压及客户端卡顿，导出保留时基。 提交问题请提供版本、最小合成输入、预期与实际结果。对接扩展可从以下方向开始：输入协议、转码预设、对象存储与播放器指标连接器，附自制影音样片。
