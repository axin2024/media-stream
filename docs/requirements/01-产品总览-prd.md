# 分布式直播与点播平台｜产品总览

**正式需求基线 v2 · Go · 独立开源项目**

Go 管理会话和作业，FFmpeg 负责编解码，MySQL 管目录与录制索引。首版以 HLS 为公开播放链路。

## 使用者与责任边界

频道主开播，导播切换输入，内容运营制作回放，观众播放授权内容，平台运维看节点与租户用量。

## 完整交付链路

频道与凭据 → 主备输入 → 转码节点 → 分发与播放 → 录制与点播 → 字幕与剪辑 → 质量与计量 → 内容运营。

## 产品范围与里程碑

| 里程碑 | 能力 | 交付物或判断依据 |
|---|---|---|
| 基础数据与首笔业务 | 频道与凭据、主备输入 | 断开主输入时备用成为唯一活动源。 |
| 贯通核心生产流程 | 转码节点、分发与播放、录制与点播 | 直播结束形成一个回放与完整分段索引。 |
| 异常、运营与独立交付 | 字幕与剪辑、质量与计量、内容运营 | 回放下架后已导出的授权剪辑按独立策略可读。 |

里程碑用于排开发顺序。首个完整公开版包含本项目全部 8 个业务域、24 项细分能力以及验收表的全部编号场景。

## 公开演示与成效

同一段自制 120 秒素材用两路推送，在第 45 秒断开主路；两档码率输出，结束后导出回放。

记录检测、切换与首个可播片段时间，切换处显式标记不连续；回放不重复计片，可定位断点并导出指定区间。

同机两路 720p 固定样片，4 秒分片条件下切换后恢复播放目标 12 秒；记录硬件及实际卡顿。以上为发布目标，验收报告须给出实测环境及原始记录。

## 边界与外部依据

观众鉴权与推流鉴权分开。技术指标区分源中断、转码积压及客户端卡顿，导出保留时基。

接口和业务术语的参考材料见 [HTTP Live Streaming](https://www.rfc-editor.org/rfc/rfc8216)。具体范围由本项目的操作契约与验收用例界定。
