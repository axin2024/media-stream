# 分布式直播与点播平台｜验收与运营

## 前置条件

在独立 MySQL 中导入可重置样例并创建两组隔离身份。演示资源包括两个本地推流器、FFmpeg、HLS 播放器与自制三分钟样片。冻结版本、输入、机器和时钟设置，接口回放与真实依赖的结果分列。

## 综合验收

**输入**　同一段自制 120 秒素材用两路推送，在第 45 秒断开主路；两档码率输出，结束后导出回放。

**通过条件**　记录检测、切换与首个可播片段时间，切换处显式标记不连续；回放不重复计片，可定位断点并导出指定区间。

在提交成功和回执返回之间断开，再使用相同标识重试。验收人同时检查 MySQL、界面和外部回执，记录业务结果数、重试次数及仍待人工处理的对象。用其他租户重复查询、下载和导出，预期可见记录为零。

## 容量与可观测性

同机两路 720p 固定样片，4 秒分片条件下切换后恢复播放目标 12 秒；记录硬件及实际卡顿。 附测量持续时间、负载构成、热身与稳定窗口、资源上限和异常分类。演练前后的持久记录须能关联到同一个请求或运行。
