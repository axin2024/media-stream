# 分布式直播与点播平台 2.0 产品需求文档

**多机位导播与节目播出控制**
需求评审版 · 2026-11-26 · 计划基线 v1.1.0（dc0f335）

## 产品目标与交付边界

当前发行覆盖频道、主备输入、HLS 输出、录制及剪辑。本版支持以下业务流程。制作人把多路直播、片头、字幕条和录播片段排入串联单，导播在预监确认后切入主输出，事后按播出日志交付节目。 [现有项目说明](../../README.md) · [上一版业务需求](02-业务与交互-prd.md)

验收用项目原创色条、时钟和合成音频，输出沿用 HLS 与现有回放入口。场内监看时延单独测量。

## 使用者与工作台

制作人排期，技术员校源，导播独占切换，包装员控制图层，播后编辑交付。

导播台同时展示四路预监、主输出和下一条节目。切换按钮读回当前控制者，失联时保留最近确认的主画面标记。播后页面可对齐计划、控制和编码三个时刻。

## 功能需求

下列六项均纳入正式版本。验收编号按项目独立，后文列出每项的触发条件和预期结果。

| 需求 | 模块 | 产品行为与约束 | 验收 |
| --- | --- | --- | --- |
| R1 | 制作台 | 制作人配置机位和声道，给每路源校时，记录备用画面和失联策略。 | A1、A2 |
| R2 | 节目编排 | 按时码设置段落和垫片，支持直播延长，重算后续项目并标记硬切时刻。 | A3、A4 |
| R3 | 预监与切换 | 预监选择下一机位，导播执行硬切或溶解，使用实际节目时码确认。 | A5、A6 |
| R4 | 图文包装 | 按授权模板叠加字幕条、台标和计时板，支持预览、定时撤下与手工清屏。 | A7、A8 |
| R5 | 播出连续性 | 主导播失联后接管控制，源失联切垫片，恢复时按当前节目钟追齐。 | A9、A10 |
| R6 | 播后交付 | 导出实际播出单、机位切点与选段，按播出版重建回看并校验音轨。 | A11、A12 |

## 页面操作与回执

| 关联需求 | 角色与入口 | 操作细节 | 需要读回的字段 |
| --- | --- | --- | --- |
| R1 · 制作台 | 技术员/源监看 | 给每路源对齐视频时钟和音频，旁路试听备用源 | slot_id、alignment_ms |
| R2 · 节目编排 | 制作人/节目串联单 | 拖动段落并检查硬时刻冲突，提交已审播出版 | rundown_rev、conflict_items |
| R3 · 预监与切换 | 导播/切换台 | 预监后执行 TAKE，读取主输出首帧时间 | take_id、actual_pts |
| R4 · 图文包装 | 包装员/字幕台 | 按模板预演字形和安全区，指定上屏时间和过期帧 | overlay_id、off_frame |
| R5 · 播出连续性 | 值班技术员/接管台 | 指定备用源、领取新控制代际并对齐主输出 | control_epoch、fallback_slot |
| R6 · 播后交付 | 播后编辑/实际播出单 | 按真实切点导出回看区间、声轨和意外中断 | asrun_rev、archive_digest |

主输出以 25 fps 的演练时基记录首帧，音频采样为 48 kHz。正常切换产生的输出时间戳倒退次数必须为零，时钟跳变单列诊断。

## 状态、权限与数据

节目 预排→预监就绪→直播→垫片或正常播出→封存，实际切点按输出时钟排序。

时间用有理数时基和帧序号表示，音频单独记录采样率。排期用 UTC 保存并显示频道本地时间。

MySQL 保存业务记录与操作回执。下列为新增逻辑对象和关键字段，所有归属组织的数据都须持有可校验的组织标识。

- `production(channel,clock)`
- `input_slot(source,offset_ms)`
- `rundown_item(rev,in_ms,out_ms)`
- `take_event(program_pts,command_id)`
- `asrun_log(segment,actual_start)`

控制代际与指令号联合去重，播出日志引用媒体片段及编码时间基。 写入前校验操作者对目标对象的权限与当前修订。详情、搜索、导出和后台重试按同一归属校验。保留决定者、请求号、前后状态、发生时间及关联证据编号。

## 核心接口与集成

主要写入入口为 `POST /productions/{id}/takes`。请求必填字段为 `slot_id, expected_control_epoch, transition, command_id`。成功回执提供 take_id, actual_pts, program_output。请求另带租户身份和幂等键。相同键及相同内容返回原业务编号，相同键对应不同内容返回 409。输入不满足业务约束时返回 422 和字段路径，身份无权限读取的跨租户对象返回 404。

需要异步处理时，接收事务同时写入业务记录与待处理事件，再返回 202 及回执查询地址。回读须显示当前状态、已完成步骤、上次失败原因和可重试条件。外部系统已受理但应答丢失时，按原请求身份核查实际结果。

### 合成请求与业务回执样例

请求体示例使用演练环境中的对象。带摘要的样例在开发验收时应替换为实际文件或参数的计算值。

```json
{
  "slot_id": "CAM-B",
  "expected_control_epoch": 5,
  "transition": "cut",
  "command_id": "C6"
}
```

业务回执示例可由提交响应或后续状态查询取得。

```json
{
  "take_id": "T6",
  "actual_pts": 45000,
  "program_output": "PGM1"
}
```

控制代际变成 6 时拒绝旧控制者的切换，并返回当前代际。actual_pts 随制作输出的时基解释。

## 升级、部署与恢复

将现有频道作为制作输出目的地，原录制索引按流代际继续可查。仅明确关联的频道接收导播输出。 在隔离副本运行迁移预检，输出记录数量、归属冲突和待处理编号。新增结构先部署，回填分批提交并保存游标，完成对账后按租户启用新入口。

演练时在首次成功写入新业务后中断进程，从检查点重启。核对实际节目时码、已播段索引、主输出及音轨摘要。需要退出试点时停收新请求，排空已受理操作并导出未决清单。涉及数据恢复时同时恢复数据库与关联证据，再核对外部已生效的动作。

## 编号验收用例

以下均为下一版待执行的验收条件。正常与异常场景使用隔离租户、固定时钟和可重置的合成数据。

| 编号 | 需求 | 操作与可观察结果 |
| --- | --- | --- |
| A1 | R1 · 制作台 | 一路晚 200 ms 时预监显示偏移及校准结果。 |
| A2 | R1 · 制作台 | 缺少有效时钟的源禁止自动切入。 |
| A3 | R2 · 节目编排 | 直播延长 30 秒只顺延非固定段落。 |
| A4 | R2 · 节目编排 | 节目超出不可移动广告窗时显示冲突。 |
| A5 | R3 · 预监与切换 | 预监切换不影响观众，执行切换后主输出只产生一次事件。 |
| A6 | R3 · 预监与切换 | 旧控制会话的切换令牌过期时拒绝。 |
| A7 | R4 · 图文包装 | 姓名条显示 5 秒后主输出撤下且留有日志。 |
| A8 | R4 · 图文包装 | 缺字体或文本溢出时阻止上线并显示预览问题。 |
| A9 | R5 · 播出连续性 | 主源中断 10 秒期间持续输出垫片并记录区间。 |
| A10 | R5 · 播出连续性 | 旧导播恢复时不得覆盖新控制者的指令。 |
| A11 | R6 · 播后交付 | 预排与实际偏差在逐段报告可核对至输出片段。 |
| A12 | R6 · 播后交付 | 缺片区间显示时长及来源，不生成完整交付标记。 |
| A13 | 全流程 | 播出 30 秒片头后进入直播，直播源失联 10 秒再恢复。播出单准确标注垫片时段，归档回看能定位该区间。 |
| A14 | 容量与可靠性 | 4 路 720p25 合成源、连续播出 60 分钟，声明机器配置，切换点音画偏差绝对值 P95 ≤ 120 ms。 |

负载报告须记录机器及依赖版本、预热和采样时长、成功数、拒绝数和超时数。验收人从工作台与业务记录两侧核对 A13，并附上原始输入、回执和最终状态。

### A13 时码核对

使用每秒有可读计数器的原创视频及同步音脉冲。比较录制文件、切点回执和实际播出单，异常区间起止偏差每端最多一帧。

## 分期交付

1. **多源同步与预监。** 交付可导入的样例和可读回的第一批业务对象，验证基础身份、归属及版本。
2. **节目单和包装。** 串通参与角色和执行入口，演练并发、重复请求及部分成功后的恢复。
3. **接管及播后核对。** 完成全流程验收、容量实测和旧版升级。随开源发行提供中文配置、样例输入输出、备份恢复步骤及已知限制。
