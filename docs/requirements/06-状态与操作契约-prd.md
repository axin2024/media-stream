# 分布式直播与点播平台｜状态与操作契约

## 直播会话的生命周期

预约→待输入→直播→降级或切换→结束→归档回放。录制产物经完整性检查才发布。

## 权限与操作者

频道主开播，导播切换输入，内容运营制作回放，观众播放授权内容，平台运维看节点与租户用量。 在待审批与已完成状态分别检查读写范围，委托与代办保留真实操作者身份。

## 两个关键交互

1. 开播请求指定频道、主备输入和转码预设，返回会话与短期凭证；断流上报包含输入代际。
2. 剪辑请求提交回放版本、起止时间和字幕轨，返回新资产、实际切点及来源区间。

## 业务操作与异常回执

| 操作域 | 在当前数据上的处理 | 冲突、拒绝或降级行为 |
|---|---|---|
| 频道与凭据 | 频道主设置活动时间窗和主备输入权限，播放资格与推流资格独立检查。 | 过期推流凭据不能抢占活动频道。 |
| 主备输入 | 监测可解码帧和最近活跃时刻，切换只接受当前代际，保留源时间和统一媒体时基。 | 迟到主源旧包不覆盖新源切片。 |
| 转码节点 | 按资源能力派发 FFmpeg 作业，节点租约和输出路径绑定代际，同频道各档采用对齐边界。 | 一种码率失败时剔除不可播档并暴露降级。 |
| 分发与播放 | 只将完整可读分片写入清单；跨时间基切换标记断点；不同画质共用可对应时间轴。 | 片段缺失时清单不能引用不存在文件。 |
| 录制与点播 | 记录真实起止时间、间隙和输入来源；生成定稿清单后才能发布点播资产。 | 结束事件重复不会产生第二份公开回放。 |
| 字幕与剪辑 | 字幕与音视频使用明确时间基，裁剪产物保留与源回放映射，关键帧引起的偏移需报告。 | 结束点早于开始点时拒绝生成。 |
| 质量与计量 | 将源中断、转码等待、出口问题及播放器信号分别统计，流量按租户与会话聚合。 | 同播放器重复心跳不重复生成一次卡顿事件。 |
| 内容运营 | 到期先撤销索引可见性，再按清单清理无引用文件；字幕、剪辑及恢复任务一起做引用检查。 | 仍有引用的源分片不能直接清除。 |

## 失联、中断及恢复

每个频道只允许一个活动输入代际；片段以会话、轨、序号唯一登记，清单只引用已完成文件。 中断后先查询最后一个已持久的业务标记，再决定安全重试、补偿或人工复核。对外回执携带对象身份及业务版本。批量操作允许逐项查看成功、失败和未开始。

## 发布级业务断言

观众鉴权与推流鉴权分开。技术指标区分源中断、转码积压及客户端卡顿，导出保留时基。 记录检测、切换与首个可播片段时间，切换处显式标记不连续；回放不重复计片，可定位断点并导出指定区间。
